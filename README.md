# JavaFX Vicsek Fractal

A fractal visualization application built using Java and JavaFX.

## About

This project generates a Vicsek fractal using a recursive algorithm. It divides a square into a 3×3 grid and recursively draws squares in five positions: the four corners and the center.

Users can change the iteration level through a text field to explore how the fractal develops with each recursive step.

## Features

- Generates the Vicsek fractal using recursion
- Divides each square into a 3×3 grid
- Recursively draws squares in the four corners and center
- Allows users to adjust the iteration level
- Supports iteration levels from 1 to 6
- Dynamically redraws the fractal when the iteration value changes

## Technologies Used

- Java
- JavaFX
- Recursion

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Allow IntelliJ to configure the project and download any required dependencies.
4. Run `HelloApplication.java`.
